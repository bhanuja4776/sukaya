# Sukaya offline preservation archive

Created 2026-08-14 from publicly accessible resources at https://sukaya.com.au/.

Start with `website-inventory.md`, `data/url-map.csv`, `data/content.json`, `data/products.json`, and the manifests. Exact server HTML is in `raw/html`; exact non-HTML responses are in `raw/responses`; downloaded binaries are in `assets`.

This archive does not invent unavailable product content. See `MISSING-DATA.md` for every recorded failure and manual-recovery need.
